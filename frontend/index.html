SoundAccess Web Player

Cliente de demostración — Authorization Code + PKCE (S256)

Esta aplicación consumirá la API de música en tu nombre. Para eso solicitará tu autorización al Servidor de Autorización SoundAccess usando el flujo Authorization Code con PKCE. La aplicación nunca ve tu contraseña.

  1. Se genera code_verifier y code_challenge = S256(verifier).
  2. Redirección a /oauth/authorize con state anti-CSRF.
  3. Inicias sesión y das tu consentimiento.
  4. Vuelves al redirect_uri con un código de un solo uso.
  5. El código se canjea en /oauth/token junto con el verifier.
